# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-31

### Added
- Per-application mouse button remapping
- Default fallback profile for all apps
- Action types: keyboard shortcut, key sequence, mouse button, double-click, app launch, shell command
- Quick presets: Mission Control, App Exposé, Spotlight, Volume, Zoom, Scroll
- Scroll wheel remapping
- Key recorder for custom shortcuts and sequences
- Diagnostics panel with button capture test
- Accessibility and Input Monitoring permission management
- Auto-save configuration on every change
- Menu bar utility (LSUIElement — no Dock icon)
